## Aim
To create a project folder and learn basic terminal navigation commands.

## Commands Used
- pwd – Shows current directory
- ls – Lists files and folders
- mkdir – Creates a folder
- cd – Changes directory
- cd .. – Moves to parent directory
- clear – Clears terminal

## Steps Performed
1. Opened the terminal.
2. Checked the current directory.
3. Created a project folder.
4. Navigated inside the folder.
5. Listed the files and folders.
6. Returned to the parent directory.
