## Aim
To understand and implement the feature-branch workflow using Git.

## Steps Performed
1. Opened the existing Git repository.
2. Created a new feature branch.
3. Switched to the feature branch.
4. Made changes to the project files.
5. Added the modified files.
6. Committed the changes.
7. Merged the feature branch into the main branch.

## Git Commands
```bash
git branch feature-update
git switch feature-update
git add .
git commit -m "Added new feature"
git switch main
git merge feature-update
git push origin main
